5.1 Fundamentals

The Physics of Memory

Lecture 5.1: Introduction to Arrays

What is an Array, actually?

To master C++, you must stop thinking of variables as abstract "containers" and start thinking of them as physical locations.

As shown in Figure 1 above, an array is a collection of elements of the same data type, stored in contiguous memory locations. "Contiguous" means they are side-by-side, sharing walls, with absolutely no gaps.

💡 The "Street" Analogy

Imagine a street where you own 5 houses in a row.

  • 🏠
    Normal Variables: scattered randomly across the city. To visit 5 friends, you drive to 5 different addresses.
  • 🏘️
    Arrays: A row of townhouses. If you know where the first house is (Base Address), and you know every house is exactly 10 meters wide, you don't need a map to find the 5th house. You just do math.

Why the +4 Jump?

In the simulator above, Address 0 is 0x100 and Address 1 is 0x104. This isn't random.

An integer in C++ physically occupies 4 bytes of RAM. Because arrays are contiguous, the next integer must start exactly where the previous one ended.

Memory Map Examples If double (8 bytes): 0x100 → 0x108 → 0x110 If char (1 byte): 0x100 → 0x101 → 0x102

🚀 Deep Dive: O(1) Access

Because memory is contiguous, the computer doesn't "search" for data. It teleports instantly using a simple math formula:

Address = Base + (Index * Size)

*Example: To find Index 2 of an int array at 100:*
100 + (2 * 4) = 108

Why do we start at 0?

It's a common confusion: "If it's the 1st element, why is the index 0?"

The Index represents "Distance", not "Count".

Think of the index as: "How many steps away from the start are we?"

  • arr[0] 0 steps from the start (The start itself).
  • arr[1] 1 step away (The neighbor).

2. Initialization Patterns (The 4 Ways)

There are four distinct ways to set the initial values of an array. Choosing the wrong one can lead to bugs.

A. Full Initialization

Safe
int arr[3] = {10, 20, 30};

Explicitly sets every value. No ambiguity. Best for small, fixed data sets.

B. Partial Initialization (The "Zero" Trick)

Pro Tip
int arr[5] = {10, 20}; // Rest becomes 0

Sets indices 0 and 1. Crucially, the compiler automatically fills the remaining slots with 0. This is the fastest way to zero-out a large array: int x[1000] = {0};

C. Implicit Sizing

Situational
int arr[] = {1, 2, 3}; // Size becomes 3

The compiler counts the elements for you. Useful when you don't want to manually count, but dangerous if you later need to append data, as the size is locked at 3.

D. No Initialization

Danger
int arr[5];

The array contains Garbage Values (random data left over in RAM from previous programs). Accessing this without assigning values first will cause calculation errors.

3. Common Algorithms

Σ Summation

Accumulates all values into a total.

int total = 0;
for(int i=0; i<SIZE; i++) {
    total += arr[i];
}

⇡ Find Maximum

Assumes first is max, then compares rest.

int maxVal = arr[0];
for(int i=1; i<SIZE; i++) {
    if(arr[i] > maxVal)
        maxVal = arr[i];
}

4. Advanced: Arrays and Pointers

If you declare: int x[5];

  • cout << x; prints the Memory Address (e.g., 0x7fff...)
  • cout << x[0]; prints the Value.
  • cout << *x; (Dereferencing) also prints the Value at index 0.

5. Special Case: Character Arrays

The Null Terminator

Computers don't know where a word ends. C++ solves this by adding an invisible character '\0' at the end of every string. If you forget space for this, your program will crash.
