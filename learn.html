5.1 THEORY

Introduction to 1D Array

An array is a fixed-size collection of elements of the same data type stored in contiguous (side-by-side) memory locations.

🧠 Memory Deep Dive

Contiguous memory ensures direct access (O(1) complexity). The address calculation is fast: Address = StartAddress + (Index * ElementSize).

1. Full Initialization

int arr[3] = {10, 20, 30};

All elements are defined.

2. Zero Initialization (Best Practice)

int arr[5] = {0};

Sets the first element to 0, which guarantees ALL elements default to 0.
