5.1 Fundamentals

The Physics of Memory

Lecture 5.1: Introduction to Data Structures & Arrays

To master C++, you must stop thinking of variables as "boxes" and start thinking of them as addresses. An array is not just a list; it is a direct reservation of physical system memory.

Definition: An array is a fixed-size homogeneous collection of elements stored in contiguous memory locations. "Contiguous" means side-by-side, without gaps. This physical arrangement is what gives arrays their speed.

Because the memory is contiguous, the computer doesn't need to "search" for the 500th element. It uses a simple math formula to teleport there instantly:

Address = BaseAddress + (Index * SizeOfElement)

5.2 Rules & Syntax

Declaration Mastery

Declaring an array tells the compiler to reserve a specific block of memory. Unlike high-level languages (like Python or JS), C++ arrays are static—their size cannot change once the program is running.

2. Initialization Patterns (The 4 Ways)

A. Full Initialization

Safe
int arr[3] = {10, 20, 30};

Explicitly sets every value. No ambiguity.

B. Partial Initialization (The "Zero" Trick)

Pro Tip
int arr[5] = {10, 20}; // Rest becomes 0

Sets indices 0 and 1. Crucially, the compiler automatically fills the remaining slots with 0. This is the fastest way to zero-out a large array: int x[1000] = {0};

3. Common Algorithms

Σ Summation

Accumulates all values into a total.

int total = 0;
for(int i=0; i<SIZE; i++) {
    total += arr[i];
}

⇡ Find Maximum

Assumes first is max, then compares rest.

int maxVal = arr[0];
for(int i=1; i<SIZE; i++) {
    if(arr[i] > maxVal)
        maxVal = arr[i];
}

5. Special Case: Character Arrays

The Null Terminator

Computers don't know where a word ends. C++ solves this by adding an invisible character '\0' at the end of every string. If you forget space for this, your program will crash.
